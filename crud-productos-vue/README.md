# CRUD de Productos (Frontend)

Aplicación web desarrollada con Vue 3 y Vite.

## 1. Configurar el archivo `.env`
Crea un archivo `.env` en la raíz del proyecto con la dirección de tu backend:

```env
VITE_API_URL=http://localhost:8080/api
```
```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

Abree en tu navegador la dirección que aparece en la terminal (por defecto http://localhost:5173). (Asegúrate de tener tu backend encendido).
